# Product Truth — SQL In Depth (sql-in-depth.vedgupta.in)

## Product Family & Platform
- **Platform**: `web` (static-first multi-page + SPA progressive enhancement, browser-native WebAssembly SQL runtime, responsive desktop and mobile).
- **Product Family**: **In-Depth Engineering Series** (github.com/innovatorved):
  1. `sql-in-depth` — Relational Algebra, Query Execution, B+Tree Storage, MVCC Concurrency & Production Database Internals (**Brand Accent**: Relational Ember `#C2410C` light / `#FB923C` dark).
  2. `system-design-in-depth` — Distributed Systems, Consensus, Caching, Replication & Large-Scale Architecture (**Brand Accent**: Distributed Teal `#0D9488` light / `#2DD4BF` dark).
  3. `dsa-in-depth` — Data Structures, Algorithmic Complexity & Pattern Visualizers (**Brand Accent**: Algorithmic Violet `#6D28D9` light / `#A78BFA` dark).

## Audience & Core Job-to-be-Done
- **Who It Is For**: Backend, data, and full-stack developers learning how relational database engines parse, plan, index, lock, and persist data.
- **Core Promise**: Every concept is taught visually and verified interactively in the browser — learners inspect 8 KB slotted pages, step through logical clause evaluation (FROM -> WHERE -> GROUP BY -> SELECT -> ORDER BY), read real EXPLAIN execution plans, and run SQLite 3 and PostgreSQL 18 queries in a zero-backend Web Worker playground.

## Aesthetic & Craft Principles
- **Tone**: Editorial technical clarity — calm, direct, diagrammatic, and open-source friendly.
- **Surfaces**: Warm Neutral Paper (`#F7F7F5` canvas, `#FFFFFF` elevated cards, `1px` crisp hairlines `#E6E4DF`) as default light mode; Neutral Charcoal (`#0F0F10` canvas, `#18181A` elevated surfaces — never harsh `#000000` glare or saturated navy) in dark mode.
- **Typography**: Self-hosted Geist (`15px` prose, `68ch` reading measure, `1.68` line-height, `28px` lesson `h1`, `20px` section `h2`) paired with Geist Mono (`tabular-nums` on every result grid, execution timer, and page offset).
- **Zero-Noise Discipline**: No pop-up consent modals blocking content, no clickbait thumbnails dominating the first viewport, no decorative left-border callout stripes, no gradient text, and sub-second page readiness with heavy WebAssembly engines isolated inside Web Workers.
